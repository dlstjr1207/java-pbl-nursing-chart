# 결과에서 제출한 기록 다시 보기 (D36, 2026-11-26)

`app.tools.ReviewCapture`(src/test)로 그린 화면이다. 프로그램과 같은 MainFrame·화면 패널을 조립하고, PC-01로 실제 제출 경로(SbarController, AI 없음)를 거쳤다. 창을 화면에 띄우지 않고 컴포넌트만 그렸다.

실습 기록은 관련 있는 메모를 관찰 서술에 그대로 붙여 넣은 것이다(결과에 "원자료를 그대로 옮겼습니다"가 나와 메모를 다시 보고 싶어지는 경우).

| 파일 | 화면 |
|---|---|
| `01-결과-제출직후.png` | 제출 직후 결과. 위에 "제출한 기록 다시 보기 (읽기 전용)" 버튼 4개 |
| `02-환자정보-읽기전용.png` | 환자 정보: 원자료 메모·처방·알레르기. 위에 "제출한 기록 보기 중 (읽기 전용)"과 "결과로 돌아가기" |
| `03-관찰-읽기전용.png` | 활력징후·관찰: 그래프와 제출한 관찰만, 입력칸 없음 |
| `04-SBAR-읽기전용.png` | SBAR: 제출한 S·B·A·R(고칠 수 없음), 제출 버튼 없음 |

| `06-개인메인-과거기록.png` | 개인 메인으로 간 뒤(보기 끝남) 과거 기록 목록 |
| `07-과거기록-결과.png` | 과거 기록을 다시 연 결과 |
