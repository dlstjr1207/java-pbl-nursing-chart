# 시연 계정(demo01) 실습 기록 (2026-11-27)

- 프로그램과 같은 창(`Main.createFrame`)을 실제 DB(MySQL)와 AI 설정으로 만들었다.
- 화면 입력칸과 버튼으로 로그인 → 실습 → 제출했다. 입력은 케이스의 모범 기록을 그대로 옮겼다(오타 없음).

## PC-01 (01~10, 기록 27)

| 파일 | 화면 |
|---|---|
| `01-PC01-환자정보.png` | 실습 시작 직후 환자 정보 |
| `02-PC01-관찰.png` | 관찰 기록 저장과 정신상태 평가 입력 |
| `03-PC01-투약.png` | 투약 5원칙을 모두 체크하고 저장 |
| `04-PC01-SBAR.png` | SBAR 입력 |
| `05-결과-AI해설.png` | 결과 화면 전체(길게 그림): 점수, 내가 제출한 기록(투약 줄 '1mg … · 구강 확인 ✓'), 실제 인계 기록 형태, 모범 기록, AI 해설 |
| `06~09-다시보기-*.png` | 제출한 기록 다시 보기: 환자 정보·관찰(정신상태 평가)·투약·SBAR |
| `10-결과로-돌아감.png` | "결과로 돌아가기" 뒤 |

정신상태 평가는 학생이 관찰해 적는 칸이다.
- 의식 수준: 환자가 말에 대답하고 걸어 다니므로 '명료(alert)'.
- 외모·행동, 기분·정동, 사고 내용: 원자료 메모의 관찰을 옮겼다.
- 메모에 없는 지각·지남력: 비워 두었다.

## AI 환자 (21~27, 기록 30)

| 파일 | 화면 |
|---|---|
| `21-AI-환자정보.png` | AI가 만든 환자로 실습 시작 |
| `22~24-AI-*.png` | 관찰(정신상태 평가 포함)·투약·SBAR 입력 |
| `25-AI환자-결과-AI해설.png` | 결과 화면 전체 |
| `26-AI환자-다시보기-환자정보.png` | 다시 보기의 환자 정보 |
| `27-AI환자-다시보기-SBAR.png` | 다시 보기의 SBAR와 실제 인계 기록 형태 |

정신상태 평가는 메모의 관찰로 채웠다.
- 의식 수준: 명료.
- 외모·행동: 사건 관찰 메모.
- 사고 내용: 환자 말 메모.
- 기분·정동: 재평가 메모의 '차분해짐'.

결과·다시 보기 화면(05~10, 25~27)은 개인 메인의 과거 기록에서 다시 열어 그렸다(프로그램과 같은 경로).

## 알아 둘 점
- 같은 시연 중 다른 기록 두 건이 더 생겼다. 지울 기록이다.
  - 28: AI 환자. 정신상태 평가 칸 배정이 어색해서 다시 했다.
  - 29: AI 생성이 5번 실패해 기본 케이스로 돌아간 PC-01.
- AI 환자의 모범 SBAR R 행에 시각이 두 번 들어가 있다("18:30 18:30 탄산리튬 투약 확인 바랍니다"). R 행 시각과 같은 시각을 중재 글에도 쓴 AI 모범 기록 그대로다.
