# 시연 계정(demo01) 실습 기록 (2026-11-27, v0.1.4-1130)

`app.tools.DemoSession`(src/test)으로 만든 기록과 화면이다.
- 프로그램과 같은 창(`Main.createFrame`)을 실제 DB(MySQL)와 AI 설정으로 만들었다.
- 화면 입력칸과 버튼으로 로그인 → 실습 → 제출했다.
- 입력은 케이스의 모범 기록을 그대로 옮겼다(오타 없음).
- 앱 클래스는 v0.1.4-1130 릴리스와 같은 빌드의 JAR에서 읽었다.
- 창을 화면에 띄우지 않고 컴포넌트만 그렸다. 비밀번호·키·DB 접속 정보는 출력하지 않았다.

정리 전 demo01 기록 6건(번호 19~24, 모두 이전 채점 기준 D30)은 사용자가 직접 지웠다.
