# AI 해설 15회 확인 (v0.1.1 → v0.1.2 수정)

v0.1.1-1130으로 다시 실습한 demo01 기록 5건(id 14~18)에, 수정한 코드로 실제 AI 해설 요청을 3번씩 보냈다(진단 도구 `app.ui.AiExplainDiag`, src/test). 해설 원문은 [15회-해설-원문.md](15회-해설-원문.md).

## 고친 것

| 문제 (v0.1.1) | 원인 | 수정 |
|---|---|---|
| ③④ 해설 '불러오지 못함' | AI가 해설 문장 속 환자 발언의 큰따옴표를 이스케이프하지 않아 JSON이 깨짐 | 따옴표가 섞인 응답을 고쳐 읽음. 그래도 못 읽으면 한 번 더 요청하고, 두 번 다 실패할 때만 FAILED. 지시문에 이스케이프 요청 |
| "학생 기록에 SpO2가 null" | 빈 활력값을 글자 그대로 "null"로 보냄 | 값이 없는 항목은 빼고, 모두 없으면 "기록 없음" |
| R 시각이 인계 이후라고 오지적 | R의 의미를 알려 주지 않음 | "R은 다음 근무자가 할 일이므로 인계 이후 시각이 맞다, 학생이 쓰지 않은 내용을 실수로 지적하지 말 것" |
| 진단·약을 "케이스에 없다"고 오지적 (확인 중 발견) | 환자 기본 정보·처방을 보내지 않음 | 환자(나이·성별·진단·입원)·알레르기·처방을 사실 자료로 보냄(개발용 표기 제외) |
| 0.5mg 입력을 "1mg 정확"이라고 함 (확인 중 발견) | 학생 투약 기록을 보내지 않음 | 학생 투약 기록(용량·재평가 계획)을 보냄 |
| '격리' 조치를 지어냄 (확인 중 발견) | 금지 대상에 간호 조치가 없음 | "간호 조치(예: 격리·강박·추가 투약)를 만들지 말 것" 추가 |
