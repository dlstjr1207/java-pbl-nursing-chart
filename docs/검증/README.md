# 단계 9 실제 창 검증 (2026-11-23)

`./mvnw package`로 만든 `target/nursing-chart-trainer.jar`의 코드로 실제 창(1280×820)을 띄우고, 개발용 도구 `app.tools.UiWalkthrough`(src/test)가 버튼을 눌러 S1~S9·V1~V7을 차례로 실행했습니다. 단계마다 창만 캡처했습니다. 계정은 합성 값입니다.

```bash
./mvnw -q -DskipTests package && ./mvnw -q test-compile
java -cp target/nursing-chart-trainer.jar:target/test-classes app.tools.UiWalkthrough <출력폴더> <db설정> <ai설정>
```
