# 보강 중 실제 AI 생성 묶음 기록 (최종 통과 전)

검사·지시를 한 단계씩 보강하며 2회씩 돌린 결과다. 묶음 순서대로: 1 새 검사 첫 적용, 2 환자 말 메모 판정 완화(따옴표 메모는 사건 메모로 봄), 3 '환자 말 메모 2개' 검사 제거(지시로만), 4 다시 요청 시 직전 케이스를 보내 고치게 함, 5 메모 순서 자동 섞기·모범 기록 고치는 법 안내. 그 뒤 알아볼 낱말 자동 보충을 넣은 최종 묶음은 AI-보강-요약.md.
