# AI 공유: 맥미니를 하루 열기

팀원과 다른 팀이 자기 PC에서 AI 기능(AI 케이스 생성·AI 해설)을 쓰게 하는 방법이다. **AI 키는 맥미니에만 두고 나눠 주지 않는다.** 맥미니에서 AI 중계 서버를 켜고, Cloudflare 임시 터널로 인터넷 주소(`https://….trycloudflare.com`)를 만들어 그 주소만 나눠 준다.

```
팀원 PC 프로그램 ──(앱 식별 헤더, 키 없음)──▶ https://….trycloudflare.com ──▶ 맥미니 cloudflared
   ──▶ 중계 서버 127.0.0.1:8787 ──(config/ai.properties의 키를 붙임)──▶ 실제 AI 서비스
```

- MySQL은 외부에 열지 않는다. 팀원 PC는 DB 설정이 없으므로 **파일 저장 모드**로 기록을 자기 PC에 저장한다.
- 임시 터널 주소는 켤 때마다 바뀐다. 끄면 그 주소는 더 이상 쓸 수 없다.

## 중계 서버가 지키는 것

| 항목 | 내용 |
|---|---|
| 키 | config/ai.properties에서 중계 서버(Java)만 읽는다. 화면·응답·접속 기록에 내보내지 않는다. 스크립트도 키 파일을 읽지 않는다(있는지만 확인) |
| 받는 요청 | `POST /v1/chat/completions`(또는 `/chat/completions`)와 연결 확인용 `GET /health`만. 나머지는 404 |
| 모델 | 서버 설정(config/ai.properties의 `ai.model`)으로 고정. 요청에서는 `messages`(system·user·assistant 글)만 옮기고 다른 칸은 버린다 |
| 앱 식별 헤더 | `X-Nursing-Chart-App: nursing-chart-trainer`가 없는 요청은 403으로 거절. 이 헤더는 브라우저나 아무 스크립트의 요청을 걸러 내는 1차 장치일 뿐 비밀번호가 아니다(공개 저장소에 있다). 그래서 하루 상한을 함께 둔다 |
| 본문 크기 | 기본 256KB를 넘으면 413 |
| 하루 상한 | 하루 전체 요청 기본 300회(맥미니 시계의 날짜 기준, 껐다 켜면 0부터). 넘으면 429 "오늘 사용량을 모두 썼습니다". 케이스 생성 1번은 요청 1~3회, 해설 1번은 1~2회 |
| 접속 기록 | `.share/relay.log`에 시각·오늘 요청 수/상한·성공/실패/거절만. 학생 기록 내용은 남기지 않는다 |
| 여는 주소 | 127.0.0.1(같은 맥)에만 연다. 같은 와이파이의 다른 PC도 터널을 거쳐야 한다 |

설정을 바꾸려면 `config/relay.properties.example`을 `config/relay.properties`로 복사해 `relay.dailyLimit` 등을 고친다(키는 넣지 않는다).

## 처음 한 번: 준비

1. **cloudflared 설치 확인.** 맥 "터미널" 앱에서:
   ```bash
   which cloudflared || echo "설치 필요"
   ```
   "설치 필요"가 나오면 설치한다(Homebrew. 비밀번호를 물으면 직접 입력):
   ```bash
   brew install cloudflared
   ```
2. 프로젝트 폴더에 `config/ai.properties`(키·모델·주소)가 있는지 확인한다. 키는 사람이 직접 넣는다.
3. 실행 JAR을 만든다(스크립트가 없으면 자동으로 만든다):
   ```bash
   ./mvnw -q -DskipTests package
   ```

## 켜기 (하루 열기)

프로젝트 폴더에서 한 줄로 켠다. 아래 1~4를 순서대로 한다.

```bash
scripts/share-start.sh
```

1. **중계 서버 켜기:** `java -cp target/nursing-chart-trainer.jar app.ai.AiRelayServer`를 백그라운드로 켜고 `http://127.0.0.1:8787/health`로 확인한다.
2. **터널 켜기:** `cloudflared tunnel --url http://127.0.0.1:8787`을 켠다(Cloudflare 계정 필요 없음).
3. **생긴 주소 확인:** 터널 기록에서 `https://….trycloudflare.com`을 찾아 화면에 보여 주고 `.share/url.txt`에 저장한다. 터널을 거쳐 `/health`도 확인한다.
4. **맥미니 잠자기 막기:** `caffeinate -dims -w <중계 서버 pid>`로 중계 서버가 켜져 있는 동안 잠자기를 막는다. 덮개를 닫는 노트북이 아니라 맥미니라 화면이 꺼져도 동작한다.

끝에 나온 `AI 서버 주소: https://….trycloudflare.com`을 팀원에게 보낸다. 주소를 다시 보려면:

```bash
cat .share/url.txt
```

## 상태 보기

```bash
tail -n 20 .share/relay.log
```

`오늘 12/300 성공`처럼 요청 수와 결과만 보인다.

## 모두 끄기

```bash
scripts/share-stop.sh
```

잠자기 막기 → 터널 → 중계 서버 순서로 끈다. 끄면 주소는 쓸 수 없고, 다음에 켜면 새 주소가 생긴다.

## 팀원 PC에서 쓰는 법

1. JDK 21을 설치하고, 받은 `nursing-chart-trainer.jar`을 실행한다(`java -jar nursing-chart-trainer.jar`). config 폴더는 필요 없다.
2. 메뉴 **설정 → AI 서버 주소…**에 받은 주소를 넣고 확인을 누른다. 상단에 "AI 서버 연결됨"이 보이면 AI 케이스 생성·AI 해설을 쓸 수 있다. 주소는 사용자 폴더(`~/.nursing-chart-trainer/ai-server.properties`)에 저장돼 다음 실행에도 기억한다.
3. 연결되지 않으면 "AI 서버 연결 안 됨"이 보이고 AI 기능만 꺼진다. 기본 케이스(PC-01)와 규칙 점검은 그대로 쓴다. 주소가 바뀌었으면 같은 메뉴에서 새 주소를 넣는다.

## 알아 둘 점

- 켠 직후 새 주소가 인터넷에 퍼지는 데 30~60초 걸린다(2026-11-26 확인: 약 40초). 스크립트가 최대 2분 기다린다.
- 하루 사용량은 중계 서버 메모리에서 센다. 중계 서버를 껐다 켜면 그날 사용량이 0부터 다시 센다.

- Cloudflare 임시 터널은 응답을 약 100초까지 기다린다. AI 응답이 그보다 오래 걸리면 그 요청은 실패하고, 프로그램은 다시 시도하거나 기본 케이스로 돌아간다.
- 임시 터널은 시험·시연용이며 사용 보장(가동 시간)이 없다. 오래 쓸 계획이면 이름 있는 터널(Cloudflare 계정)을 따로 검토한다.
- 이 PC(맥미니)에서 프로그램을 쓸 때는 config/ai.properties의 키를 그대로 쓴다(키 파일이 있으면 AI 서버 주소보다 먼저).

## 확인 기록 (2026-11-26)

맥미니에서 `scripts/share-start.sh`로 중계 서버·터널·잠자기 막기를 켜고, 새로 빌드한 JAR을 config가 없는 다른 폴더에 두고 주소만 넣어 확인했다(점검 도구 `app.tools.RelayE2ECheck`, 프로그램과 같은 순서로 조립. 화면을 직접 누른 확인은 아님).

| 항목 | 결과 |
|---|---|
| 헤더 없이 /health | 403 |
| 연결 | "AI 서버 연결됨", 오늘 남은 사용량 300회 |
| AI 케이스 생성 | 성공, 136초(2번 시도, 각 요청은 100초 안) |
| 모범 기록 제출 | 100점 |
| AI 해설 | 성공, 11초 |
| 접속 기록 | `오늘 1/300 성공`처럼 시각·요청 수·결과만 |
| 끄기 | `scripts/share-stop.sh` 뒤 cloudflared·중계 서버·caffeinate 프로세스 없음 |
