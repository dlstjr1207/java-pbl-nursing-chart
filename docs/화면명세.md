## 2. 화면별 명세 (화면마다 복사해서 채운다)

```
### 화면 N. <이름>
- 목적: 
- 사용자가 하는 일: 
- 화면에 보이는 데이터(시나리오 JSON의 어느 항목): 
- 입력 칸: 
- 버튼·이동(어느 화면으로): 
- 문구는 시안 그대로 쓸 것: 예 / 아니오
- 임상 용어가 있는가: 있으면 근거 ID
- 완료 조건(관찰할 수 있게): 
```

## 4. 디자인 규칙

- 색·글꼴·간격은 '컬러차트' 페이지와 '컴포넌트 가이드' 프레임을 기준으로 한다. `TODO(디자인 담당)`: 값을 이 문서에 적는다(예: 주 색상 #xxxxxx, 본문 글꼴 크기 nn).
- 화면 크기: `TODO(디자인 담당)`: 기준 해상도(예: 1280×800)

## 5. 구현 시 지켜야 할 것 (Claude에게도 그대로 적용)

- 디자인에 없는 요소를 추가하거나 문구·색·배치를 바꾸지 않는다.
- 화면의 임상 값은 하드코딩하지 않고 시나리오 JSON에서 읽는다.
- 화면에 `검증필요` 데이터가 있으면 "교육용 예시 · 임상 검수 전"을 표시한다.
