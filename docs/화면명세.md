## 2. 화면별로 디자인에서 읽은 내용

> 모든 화면은 **가상 환자 한 명의 예시 데이터**로 채워져 있다(아래 3장). 글자는 읽은 것만 적었다.

### 화면 3. 환자 정보 종합
- 구성(큰 제목 수준): 위급 위험·임상 사정 지표(Triage Indicators), 치료 진척 사정·입원 경과 요약, **주 증상(CHIEF COMPLAINT)**과 정신과 입원 사유, 약물 알레르기·주 정신과 약물 부작용(ADR), 현재 입원 처방(Inpatient Regimen) `[확인필요: 소제목 글자를 정확히 읽지 못함]`
- 화면에 영문 진단 표기 `(Schizoaffective)`가 보인다(앞의 한글 진단명은 글자가 작아 읽지 못함) `[확인필요]`.
- 입력 칸: 보이지 않음.

### 화면 4. 정규 루틴 투약 점검
- **약물 목록과 시간대별 복용 상태 표**: 예) 리튬(Lithium Carbonate, 기분 안정제, ATC 코드 표기), 로라제팜 0.5mg(항불안제), 마그밀 500mg(완화제). 약마다 용량·경로(P.O)·식후 표시와 복용 표시
- **주의 문구:** 당뇨병성 케톤산증 병력 환자의 항정신병제 투약 시 혈당·체중 모니터링 안내
- **최근 6개월 항정신병제·기분안정제 용량 조절·스위칭 이력** 타임라인: 아리피프라졸 10mg + 리튬 900mg/day 유지, 혈중 리튬 농도 0.78 mEq/L, 벤즈트로핀 추가 등
- **추체외로증상(EPS) 사정(SAS/BARS)**: 진전/운동완만, 급성 근긴장이상, 좌불안석증, 지연성 운동이상증(AIMS) 등 항목
- **구강 은닉 검사(Cheeking Check)**: 확인 완료 표시
- 상단에 투약 진행·정신과적 경계(Vigilance) 요약 막대

### 화면 5. 활력징후 & 이상행동 관찰
- **활력징후 추이 차트는 유지한다(D14).** 예: 09:30 PRN 로라제팜 투약 시점을 표시한 선 그래프(HR 94 → 11:30 HR 80)
- **불안 VAS 시계열 차트는 제거한다(D14).** 레이어 이름상 'V/S 추이 + 불안 VAS 시계열' 이중 차트(`Row 2: Dual Dynamic Charts`)이므로, 디자인에서 **VAS 시계열 쪽만 지운다** `TODO(디자인 담당)`
- **이상행동 실시간 관찰 로그**: 시각 + 근무 + **분류 태그**(예: '안정 회복', '불안 급증·PRN 투여') + **서술** + 처치 + 기록자 + 그때의 V/S. 서술 안에 환자 발언이 **따옴표로 인용**되어 있음
- **15분 간격 안전 라운딩**(자해 감시 Tier 2): 시간별 확인 체크박스(13:45 침상 안정 확인, 14:00 데이실 프로그램 참관, 14:15 병실 내 도서 열독 중, 14:30 현재 예정 라운딩)
- 소지품(위험 물품) 점검 표시 `[확인필요]`
- 이름에 'Restraints'가 있으나 **격리·강박 기록은 확인하지 못했다** `[확인필요]`. 기획안은 격리·강박을 범위 밖으로 둔다

### 화면 6. SBAR 듀티 인계 리포트
- **S · B · A · R 네 개 영역**
  - **S** Situation: 현재 상황·위험 지표
  - **B** Background: 병력·약물 요약
  - **A** Assessment: 현재 임상 사정과 **MSE 평가 요약**(사고내용, 지각·병식 등), 구강 은닉 검사
  - **R** Recommendation: 다음 듀티의 시간별 **필수 중재 체크리스트**(체크박스)
- **PRN 약효 평가** 문장이 포함됨: "투약 40분 후 재사정: 주관적 불안 VAS 8점에서 2점으로 경감, RASS 0점". 기록 시각 표시
- 자해 위험 척도 표시 `[확인필요]`, 하단에 인계 확인 영역 `[확인필요]`

### 화면 1·2. 로그인, 개인 메인
- **디자인이 없다.** 로그인 프레임은 비어 있다.
- 개인 메인은 아래를 담을 것으로 정했다(팀 의견, 아직 안 그림): 실습 시작, 과거 실습 기록, 평가지표, 로그아웃.

## 3. 디자인이 가정하는 환자 (예시 데이터)

화면 안의 가상 환자는 **병실 502호, 진단 'Schizoaffective'로 표기, 아리피프라졸 + 리튬 + 로라제팜(PRN) + 벤즈트로핀, 혈중 리튬 0.78 mEq/L, 자해 감시 Tier 2** 로 보인다 `[확인필요]`. 이 환자를 **MVP의 PC-01로 쓴다(D16).** [환자케이스.md](환자케이스.md)의 이전 케이스(조현병 급성기, 우울+자살사고, 양극성 조증)는 PC-11~13으로 이름을 바꿔 2차 후보로 두었다.

## 4. 디자인이 요구하는 데이터 항목 (환자 케이스 JSON에 들어가야 하는 것)

| 화면 | 필요한 데이터 |
|---|---|
| 환자 정보 종합 | 인적사항, 진단, 입원 사유·주 증상, 약물 알레르기·부작용, 현재 처방, 위험 지표 |
| 정규 루틴 투약 | 약물 목록(성분, 용량, 경로, 시간), 시간대별 복용 상태, 용량 조절 이력, 혈중 리튬 농도, EPS 사정 항목(SAS/BARS/AIMS), 구강 은닉 검사 결과 |
| 활력징후 & 이상행동 | 시간별 활력징후(값 + **추이 차트 유지**, VAS 시계열은 제거), 관찰 로그 목록(시각, 태그, 서술, 처치, 기록자), 안전 라운딩 일정, 소지품 점검 |
| SBAR | S·B·A·R 내용, PRN 평가(VAS, RASS), MSE 요약, 다음 듀티 중재 체크리스트 |

> 이 항목들은 **임상 데이터가 매우 많다.** 근거 없이 채울 수 없으므로 [근거표.md](근거표.md)와 연결되어야 한다. 범위는 [기획안](기획안.md) 2장(환자 1명, EPS는 표시만)에 따른다.

## 5. 범위에서 빠지는 화면 (2차 또는 제외)

|---|---|---|
| 간호 기록 및 바이탈·상담 (Nursing Notes & MSE) | 2차 | 학생 작성 화면 후보였으나 이번엔 제외 |

| 리튬 TDM 검사·일정 | 2차 | 혈중 리튬 농도는 정규 투약 화면에 표시 |
| Full-Battery / MMPI 결과 | 제외 | 범위 밖 |
| To-Do 예정 처치·지시사항 | 제외 | 범위 밖 |
| 격리·강박(Restraints) 기록 | 제외 | 범위 밖(기획안, 근거표 E-19) |

## 6. 정리해야 할 디자인 항목

1. **모든 화면의 왼쪽 EMR 메뉴**에 제외된 화면의 항목(리튬 TDM, MMPI, To-Do 등)이 남아 있다. MVP 화면으로만 줄여야 한다. `TODO(디자인 담당)`
2. 화면 제목이 **한글+영어 혼용**이다(예: "환자 정보 종합 (Patient Overview)"). 구현할 때 어느 쪽을 쓸지 정한다.
3. **불안 VAS 시계열 차트만 제거한다(D14).** 활력징후 추이 차트는 남긴다. 관찰 로그 서술 안의 "VAS 8점" 같은 문장은 글이므로 그대로 둔다. 활력징후 추이 차트의 구현 방식(Swing 커스텀 그리기 vs 라이브러리)은 `TODO(팀)`.
4. 화면이 **세로로 길다**(1658~1875px). 스크롤 영역으로 구현한다.
5. 로그인·개인 메인·(학생이 쓰는 입력 화면)·결과 화면을 **새로 그려야 한다.**

## 8. 디자인 규칙

- 색·글꼴·간격은 '컬러차트' 페이지와 '컴포넌트 가이드' 프레임을 기준으로 한다. `TODO(디자인 담당)`: 값을 이 문서에 적는다.
