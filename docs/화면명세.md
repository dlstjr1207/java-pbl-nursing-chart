# 화면명세

기능 ID는 [기획안](기획안.md)을 따른다. Figma는 화면 배치의 참고 자료이며, 아래 표는 구현할 동작을 정의한다. 2026-11-16에 확인한 원본과 차이는 [디자인 검토](design/디자인검토.md)에 기록했다.

## 화면 구성

기본 6화면과 회원가입 보조 화면으로 구성한다.

| 화면 | 관련 기능 | 조회·입력 | 이동·결과 |
|---|---|---|---|
| 로그인 | F-13 | 아이디, 비밀번호 | 성공 시 개인 메인, 실패 시 공통 오류 안내 |
| 회원가입 | F-13 | 이름, 아이디(영문·숫자 4~20자), 비밀번호(8자 이상)·확인 (D23) | 형식·중복 아이디 거부, 가입 후 로그인 |
| 개인 메인 | F-01, F-09~11 | 실습 시작(사건 유형 선택 또는 기본 케이스), 평가지표, 과거 기록, 결과 패널 | 케이스 진입, 기록 상세, 로그아웃 |
| 환자 정보 종합 | F-02 | 환자 정보·진단·처방·알레르기·위험 지표 | 관찰·투약·SBAR로 이동 |
| 활력징후·관찰 | F-03, F-04 | 활력징후 값·추이, 기존 로그, 상황 자료, 관찰 입력 | 입력 검증 후 학생 기록 저장 |
| 투약 점검 | F-05 | 처방·기존 투약 상태, 학생 투약 입력 | 입력 검증 후 학생 기록 저장 |
| SBAR 인계 | F-06 | 참고 자료, S·B·A·R 입력 | 제출 후 개인 메인 결과 패널 |

## 공통 구성

- 실습 화면의 이동 메뉴: 개인 메인, 환자 정보, 활력징후·관찰, 투약 점검, SBAR, 로그아웃.
- 현재 환자·실습·로그인 사용자를 모든 화면에서 동일하게 표시한다.
- 케이스 정보와 기존 기록은 읽기 전용, 학생 기록은 입력 영역으로 구분한다.
- 필수 입력 오류가 있어도 작성 내용은 유지한다. 안내는 문제가 있는 항목과 연결한다.
- 정답 키와 모범 기록은 제출 후에만 표시한다. 제출 전 참고 영역에 완성된 정답을 그대로 노출하지 않는다.
- 긴 본문은 스크롤로 처리하며, 저장·제출 버튼과 오류 문구가 가려지지 않도록 한다.
- 화면에 `교육용 예시 · 임상 검수 전`을 표시한다. DEMO 케이스(D25)로 실습 중이면 모든 화면에 `DEMO · 실제 케이스 아님`을 표시한다.

## 입력과 검증

| 입력 | 필수·조건 | 저장 내용 |
|---|---|---|
| 관찰 | 시각, 근무, 태그 1개 이상, 서술 | 서술·처치·선택적 활력징후를 입력 그대로 보존 |
| 투약 | 처방 선택, 용량·단위, 경로, 시각, 결과, 처방 근거 | PRN·거부·보류는 사유 필수. 구강 확인과 재평가 계획 포함 |
| SBAR | S·B·A 텍스트, R의 시각·중재 행 | 빈 영역을 안내하고 제출을 보류. 완성 시 실습 결과 저장 |

관찰 화면에는 이미 빠른 서술 입력란과 태그·등록 버튼이 있다. 이 영역을 확장할지 별도 입력 창을 사용할지는 디자인에서 확정한다. 관찰 기록 목록에는 학생 기록만 시각 순으로 보인다. 케이스의 기존 관찰 로그(observationLog)는 정리된 문장이라 원자료 메모를 대신 정리해 주는 셈이므로 학생 화면에 보이지 않는다(데이터는 남기고 AI 해설 사실 자료로만 쓴다). 활력징후 그래프는 그대로 둔다.

투약 선택지는 해당 케이스의 처방 목록에서 제공한다. 투약 기록 자체의 필수값 검증과, 입력한 값이 케이스와 맞는지 확인하는 R7 채점은 구분한다. 입력값이 처방과 다르다는 이유만으로 저장을 막아 오류 연습을 불가능하게 만들지 않는다.

## 개인 메인과 결과

실습 시작 시 AI 생성 중 상태를 표시하고, 실패하면 PC-01(없으면 DEMO)로 진행한다는 안내를 보여 준다. 키가 없거나 허용 약물 목록이 비어 있으면 생성 선택지 대신 그 이유를 표시한다. AI 생성 케이스에는 모든 화면에 `AI 생성 · 임상 검수 전`을 표시한다(F-14).

평가지표는 총 실습 횟수, 최근 점수, 항목별 평균, 최근 5회 추이다. 과거 기록에는 제출 시각·케이스·점수·상세 보기를 표시한다. 아직 산출할 수 없는 점수는 미산출 상태로 표시한다.

결과 패널은 잘 작성한 내용, 누락, 불일치를 구분하고 해당 입력칸·문장을 표시한다. 모범 기록, AI 해설 상태, 다시 실습하기를 함께 제공한다. 과거 기록은 제출 당시 입력과 결과를 보여 준다. 다른 사용자의 기록은 조회되지 않는다.

활력징후 추이는 포함하고 VAS 시계열은 포함하지 않는다. 현재 MVP 프레임 밖에 있는 차트는 배치를 다시 정해야 한다.

실시간 채팅·긴급 호출, 인쇄·PDF·서명, 격리·강박 기록과 후속 메뉴는 기능 구현 대상이 아니다. 부가 영역을 접거나 안내용으로 남길지는 디자인 보완 항목이며, 작동하는 기능처럼 표시하지 않는다.

## 화면 완료 기준

화면별 조회 데이터, 입력 검증, 저장 결과, 다음 화면 이동을 시나리오와 대조한다. 실제 실행 크기에서 글자 잘림·줄바꿈·스크롤·포커스 순서를 확인한다. 확정된 시안과 구현 화면을 비교하고 차이를 기록한다.
