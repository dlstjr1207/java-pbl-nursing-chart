# demo01 시연 실습 5회 (v0.1.2-1130)

- 일시: 2026-11-24, 릴리스 [v0.1.2-1130](https://github.com/dlstjr1207/java-pbl-nursing-chart/releases/tag/v0.1.2-1130) JAR(main `8da2e38`)로 실행. 릴리스에서 받은 JAR과 직접 빌드한 JAR의 해시가 같음을 확인
- 실행: 실제 메인 창(`Main.createFrame`)을 띄우고 `UiWalkthrough`의 `demo5` 모드로 입력칸에 글을 넣고 버튼을 눌러 제출. 저장은 MySQL, AI 해설·AI 케이스 생성 켬
- 계정: [docs/시연계정.md](../시연계정.md). 이전 버전으로 만든 기록은 모두 지우고(사용자가 SQL로 삭제) 새로 실습했다
- 학생 문장은 회마다 직접 썼고, 모범 기록 문장을 복사하지 않았다. ⑤는 도구가 AI 환자를 만든 뒤 멈추면 그 환자의 브리핑을 보고 문장을 써서 넣었다
- 채점 규칙·배점은 바꾸지 않았다

## 결과표

| 회 | 환자 | 의도한 실수 | 점수 | 틀린 항목 | AI 해설 이상 여부 |
|---|---|---|---|---|---|
| ① | 김하늘 (PC-01) | 없음 (모범에 가까운 기록) | **100** | 없음 | 없음 (참고: "A에 투약 전 VAS 8을 함께 쓰라"고 했으나 학생은 이미 "VAS 8→2"를 씀) |
| ② | 김하늘 (PC-01) | 투약 용량 0.5mg | **95** | R7 용량 불일치 ('0.5', 기준 '1') | 없음. 0.5mg 불일치를 정확히 지적 |
| ③ | 김하늘 (PC-01) | 발언을 따옴표 없이 바꿔 씀 + '협조적' | **90** | R1 따옴표 인용 누락 (0/10). '협조적' 판단 표현 피드백(배점 없음) | 없음. 예시에 케이스의 실제 발언만 인용 |
| ④ | 김하늘 (PC-01) | 재평가 계획 없음 + SBAR R 한 줄 | **86.7** | R4 재평가 계획 누락 (0/10), R2 관찰의 재평가 누락 (16.7/20). R9 '18:30 리튬 투약' 없음 피드백(배점 없음) | 없음 |
| ⑤ | 송미연 (GEN-20261124-0034, AI 생성) | 재평가 계획 누락 (용량은 일부러 "1.0mg"으로 씀) | **86.7** | R4 재평가 계획 누락 (0/10), R2 관찰의 재평가 누락 (16.7/20). "1.0mg"은 감점 없음 | 없음. 실제 발언("너무 불안해요")과 실제 수치(15:10 BP 115/75, HR 72)만 씀 |

- 5회 모두 의도한 실수만 감점되었다. 5회 모두 AI 해설을 받았다(SUCCESS).
- AI 해설 이상 여부는 다섯 해설을 하나씩 읽고 확인했다. 확인 항목: 케이스에 없는 발언·수치·사건·간호 조치, 빈 값(null) 지적, R 시각 오지적.
- 결과 화면 상단에는 매번 환자 이름과 케이스 ID가 보였다.

## 알려진 한계 (채점 규칙은 바꾸지 않음)

1. **R6은 구강 확인 체크를 점검하지 않는다(후속 범위).**
2. 결과 문구의 조사가 어색하다: "재평가을(를)", "경로이(가)" 등.
3. AI 해설은 매번 달라진다. 지어내기 금지와 사실 자료를 넣었지만 해석 표현(예: "망상적 사고")이나 깨진 단어가 드물게 나올 수 있다. 점수에는 반영되지 않는다.

## 추천 시연 순서

1. ① 100점: 결과 화면 구성(총점 → 항목별 막대 → 고칠 점 없음 → 모범 기록 공개 → AI 해설)
2. ③ 판단 표현: 따옴표 인용 누락(R1 0점)과 '협조적' 피드백(배점 없음)의 차이
3. ② 용량 0.5mg: 투약 값 불일치가 주황색 '불일치'로 보이는 모습
4. ⑤ AI 환자: AI 생성 케이스(ID·임상 검수 전 표시), "1.0mg"으로 써도 감점되지 않는 것, 실제 사실만 인용하는 AI 해설
5. (시간 있으면) ④ 재평가 누락과 SBAR R 피드백
