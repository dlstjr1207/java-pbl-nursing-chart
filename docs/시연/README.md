- 채점 규칙·배점은 바꾸지 않았다

5회 모두 의도한 실수가 예상한 규칙에서 잡혔고, 다른 감점은 없었다. 5회 모두 AI 해설을 받았다(SUCCESS). 결과 화면 상단에는 매번 환자 이름과 케이스 ID가 보였다.

### ⑤ 다시 실습 (용량 버그 수정 후)

처음 ⑤(홍준영, GEN-20261123-2235, 83.3점)는 두 가지 문제가 있어 다시 실습했다.

- **용량 표기 버그:** AI 처방 용량이 `1.0`이라 관찰 서술의 "1.0mg"이 정답 키 `1mg|1 mg`과 맞지 않아 R2 '투약'이 누락으로 잡혔다. 채점 비교에서 숫자 끝 `.0`을 없애 "1.0mg"·"1.0 mg"·"1mg"을 같은 값으로 보게 고쳤고(학생 기록과 정답 키 모두), AI 케이스를 저장할 때 처방·정답 키·모범 투약 기록의 `1.0`을 `1`로 정리한다. "0.5mg"은 계속 틀린다. 배점·판단 기준은 그대로다.
- **입력 문장:** 도구가 정답 키 단어를 이어 붙여 "서성 모습이 보임" 같은 문장이 생겼다. 다시 할 때는 도구가 AI 환자를 만든 뒤 사실(브리핑·처방·활력징후)을 파일로 남기고 멈추면, 사람이 그 환자에 맞는 문장을 써서 넘겼다.

새 ⑤에서는 관찰 서술과 투약 기록에 일부러 "1.0mg"·"1.0"을 썼고, R2 '투약'과 R7 용량이 모두 통과했다. 의도한 실수(재평가 계획 누락)만 R2 재평가·R4에서 잡혔다.

중간에 한 번 더 실습한 기록(정준혁, GEN-20261123-2247, 86.7점)이 있다. 이때 AI 해설이 학생이 쓴 실제 활력징후 값을 "케이스에 없는 수치"라고 잘못 지적했다. 해설 요청에 브리핑만 보내고 활력징후·관찰 로그는 보내지 않았기 때문이다. 이를 고친 뒤 안서윤으로 다시 실습했다. 이 기록과 처음 ⑤ 기록은 삭제 대상이다(아래 SQL).

### AI 해설이 없는 사실을 만들지 않게

처음 ③의 해설 예시에 케이스에 없는 환자 발언("너무 불안하고 마음이 안 잡혀요")이 들어갔다. 해설 지시문과 요청 글에 "케이스와 학생 기록에 없는 환자 발언·수치·사건을 만들지 말 것. 예시 문장에는 케이스의 실제 발언만 인용할 것"을 넣었다. 요청에는 케이스 브리핑·활력징후·관찰 로그와 학생 관찰 기록을 사실 자료로 함께 보낸다(정답 키·모범 기록은 보내지 않음). 새 ⑤ 해설의 예시는 케이스의 실제 발언("머릿속이 너무 복잡하고 무서워요")과 실제 수치(11:30 BP 115/75, HR 76)만 썼다. ①~④의 해설은 수정 전에 받은 것이라 그대로 두었다.

### 기존 ⑤ 기록 삭제 (사용자가 직접 실행)

```sql
-- 확인: 지울 2건만 나와야 한다 (id 11, 12)
SELECT a.id, u.login_id, a.case_id, a.submitted_at, a.score
FROM attempts a JOIN users u ON u.id = a.user_id
WHERE u.login_id = 'demo01' AND a.case_id IN ('GEN-20261123-2235', 'GEN-20261123-2247');

-- 삭제: 관찰·투약·SBAR·점검 결과는 ON DELETE CASCADE로 함께 지워진다
DELETE a FROM attempts a JOIN users u ON u.id = a.user_id
WHERE u.login_id = 'demo01' AND a.case_id IN ('GEN-20261123-2235', 'GEN-20261123-2247');
```

## 알려진 한계 (채점 규칙은 바꾸지 않음)

1. **R6은 구강 확인 체크를 점검하지 않는다(후속 범위).** 처음 ⑤에서 구강 확인을 체크하지 않았는데 R6이 만점이었다.
2. 결과 문구의 조사가 어색하다: "재평가을(를)", "경로이(가)" 등.
3. ①~④의 AI 해설은 지어내기 금지를 넣기 전에 받은 것이다. ③ 해설 예시에는 케이스에 없는 발언이 남아 있다.

## 추천 시연 순서

1. ① 100점: 결과 화면 구성(총점 → 항목별 막대 → 고칠 점 없음 → 모범 기록 공개)
2. ③ 판단 표현: 따옴표 인용 누락(R1 0점)과 '협조적' 피드백(배점 없음)의 차이
3. ② 용량 0.5mg: 투약 값 불일치가 주황색 '불일치'로 보이는 모습
4. ⑤ AI 환자: AI 생성 케이스(ID·임상 검수 전 표시), "1.0mg"으로 써도 감점되지 않는 것, 실제 사실만 인용하는 AI 해설
5. (시간 있으면) ④ 재평가 누락과 SBAR R 피드백
