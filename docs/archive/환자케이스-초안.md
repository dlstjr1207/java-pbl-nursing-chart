| 2차 후보 | PC-11 조현병 급성기·복약 거부 / PC-12 우울·자살사고 / PC-13 양극성 조증 | 이 문서 아래쪽. 이전 초안(대화록 방식) |

JSON 변환 매핑(구현 때 사용): 메타 → `id,title,difficulty,objectives` / 환자 → `patient` / 처방·투약 → `orders` / 활력징후 → `vitals` / 기존 관찰 로그 → `observationLog` / 안전 라운딩 → `safetyRounds` / **상황 브리핑 → `briefing`** / 정답 키 → `answerKey` / 모범 기록 → `modelAnswer` / SBAR 참고 → `sbarReference`

## 이 문서를 고치는 방법 (팀원용)

1. 임상 주장(약, 용량, 수치, 간호 중재, 관찰 항목)을 하나 골라 [근거표.md](../근거표.md)에서 근거를 찾고, 문장 끝에 근거 ID를 단다. 예: `(E-09)`. 그리고 `[검증필요]`를 지운다.
2. 근거가 없거나 등급 C뿐이면 `[검증필요]`를 남기고 근거표 'G-xx' 담당자에게 알린다.
3. `[확인필요]`는 **Figma 화면과 대조**해서 고친다. 디자인이 틀렸으면 디자인도 같이 고친다.
4. 고친 뒤 [결정기록.md](../결정기록.md)에 한 줄 남긴다.
