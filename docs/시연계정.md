# 시연 계정 (demo01)

발표·시연 때 쓰는 계정이다. 저장소가 공개라서 **이 비밀번호는 시연 전용 값**이며, 실제로 쓰는 어떤 비밀번호와도 다르다. 다른 곳에 재사용하지 않는다.

| 항목 | 값 |
|---|---|
| 아이디 | `demo01` |
| 이름 | 시연 학생 |
| 비밀번호 (시연 전용) | `sian-demo-84573f` |
| 저장 위치 | MySQL `nursing_chart` (발표 PC의 `config/db.properties` 기준) |

## 로그인 방법

1. `config/` 폴더가 있는 프로젝트 폴더에서 `java -jar nursing-chart-trainer.jar`를 실행한다 (릴리스 v0.1.0-1130의 JAR 또는 `./mvnw package` 결과).
2. 로그인 화면 아래에 "파일 저장 모드" 안내가 **없는지** 본다. 안내가 보이면 MySQL에 연결되지 않은 것이라 demo01 기록이 보이지 않는다.
3. 아이디 `demo01`, 위 비밀번호로 로그인하면 개인 메인에 실습 기록 5건이 보인다. 기록을 누르면 결과 화면이 열린다.

다른 PC(MySQL에 demo01이 없는 곳)에서는 같은 이름·아이디·비밀번호로 회원가입하면 된다. 실습 기록은 그 PC의 DB에만 쌓인다.
