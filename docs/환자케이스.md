# 환자 케이스

첫 버전의 실습 대상은 PC-01 한 명이다. 이 문서는 화면과 정답 데이터의 기준을 관리한다. 상태는 초안(DRAFT)이며, 임상 근거 확인과 기준값 확정이 남아 있다.

**PC-01의 역할 (D20):** AI 생성 케이스의 견본, AI 키가 없는 PC의 기본 케이스, 테스트용 고정 케이스다. AI 생성을 쓰더라도 PC-01의 기준값은 확정해야 한다.

## PC-01: 관찰·투약·인계

불안이 높아진 가상 환자에게 시행된 간호와 PRN 투약, 이후 관찰을 기록하고 다음 근무자에게 인계하는 상황이다. 학습 목표는 환자 발언과 관찰 사실 구분, 투약 정보의 정확한 기록, 재평가와 SBAR 연결이다. 예상 소요 시간은 12~15분이다.

## AI 생성 케이스의 기준

AI가 케이스를 만들 때 따르는 틀이다. 아래는 **후보**이며 팀이 확정한다. 근거가 확인되지 않은 항목은 `[검증필요]`다.

| 사건 유형(후보) | 학생이 기록할 핵심 | 관련 점검 | 첫 도입 |
|---|---|---|---|
| 불안 증가 → PRN 투약 → 재평가 | 행동·발언 인용, PRN 사유·용량, 재평가 | R1, R2, R4, R6, R7 | ✓ (PC-01과 같은 유형) |
| 복약 거부 | 거부 사유 인용, 결과·사유, 보고 | R1, R6 | 후보 |
| 구강 은닉 의심 | 관찰 사실, 확인 절차, 보고 | R1, R2 | 후보 `[검증필요]` E-24 |
| 초조·공격적 언행 | 행동 기술, 중재, 안전 조치 | R1, R2, R5 | 후보 |
| 약물 부작용(급성 근긴장이상 등) | 증상 관찰, 활력징후, 보고·처치 | R2, R7 | 후보 `[검증필요]` E-14·E-23 |
| 자해 위험 발언 | 위험사정 | R3 | **후속**(R3이 후속 범위) |

- **허용 약물·용량 범위:** 근거표에서 허가사항을 확인한 약만 넣는다(현재 E-20 아리피프라졸, E-21 리튬은 부분 확인). 확인 전인 약은 생성에 쓰지 않는다.
- **유형별 필수 사실 항목:** 각 유형의 사건 시각·장소·행동·발언·간호·투약·재평가 중 무엇이 반드시 있어야 하는지 정한다. 이 항목이 R2·R8의 기준이 된다.
- 생성된 케이스는 임상 검수를 거치지 않는다. 화면에 `AI 생성 · 임상 검수 전`을 표시한다.

정규와 PRN 처방의 차이, 서로 다른 시각의 측정값은 그 자체로 오류가 아니다. 동일 사건·동일 처방인지 먼저 확인한다. 허가사항만으로 가상 환자의 처방을 자동 결정하지 않는다. 케이스 작성자가 교육 목표와 근거를 바탕으로 정하고 변경 이유를 남긴다.

## 원자료와 기록 구성

학생에게는 환자 정보, 처방, 기존 관찰 로그, 상황 브리핑을 제공한다. 정답 키와 모범 기록은 제출 후 공개한다.

관찰 브리핑 초안에는 장소와 행동, 환자의 직접 발언, 시행한 간호, PRN 투약 사실, 재평가 계획을 포함한다. 핵심 상황 초안은 데이실에서 손톱을 과도하게 물어뜯는 행동, 감시당하는 것 같다는 환자의 발언, 진정 지지 간호, 구두 처방에 따른 투약이다. 임상 표현과 세부값은 근거 확인 후 확정한다.

11:30 후속 관찰이 기존 로그로 제공되는 경우 학생이 같은 기록을 다시 저장할 필요는 없다. 새 관찰 기록과 기존 후속 기록을 구분하고, 재평가 연결은 해당 사건의 시각과 내용으로 확인한다.

## 정답 키와 모범 기록

| 입력 | 필수 요소 | 점검 |
|---|---|---|
| 관찰 기록 | 분류, 장소·행동, 환자 발언 인용, 시행한 간호, 투약의 약명·용량·경로, 재평가 계획 | R1, R2, R4, R8 |
| 투약 기록 | 적용 처방, 약명·용량·단위·경로·시각, 결과, 사유, 처방 근거, 재평가 계획 | R4, R6, R7 |
| SBAR | 사건과 현재 상태, 관련 배경, 사정, 다음 근무의 시각별 중재 | R8, R9 |

다음은 문장 구성용 틀이다. 중괄호 값은 확정 케이스에서 대입하며, 그대로 제출하거나 만점 테스트에 사용하지 않는다.

> {{장소}}에서 {{관찰 행동}}이 관찰됨. 환자는 "{{직접 발언}}"이라고 말함. {{시행한 간호}} 후 {{처방 근거}}에 따라 {{약명}} {{용량과 단위}} {{경로}} 투여. {{재평가 시각과 확인 내용}}을 계획함.

투약 기록과 관찰 서술의 용량·시각은 같은 처방을 참조해야 한다. 모범 기록에 용량이 빠진 상태로 모든 점검이 통과한다고 가정하지 않는다. 표현의 허용 범위와 점검 가중치는 기획안의 미결 사항이다.

## 데이터 변환

| 문서 자료 | JSON 항목 |
|---|---|
| 케이스 정보 | id, title, difficulty, objectives, reviewStatus |
| 환자·알레르기·위험 지표 | patient, adr, riskTier |
| 처방·변경 이력·농도 | orders, regimenHistory, lithiumLevel |
| 측정·기존 기록 | vitals, observationLog, safetyRounds |
| 제출 전 자료 | briefing, sbarReference |
| 제출 후 자료 | answerKey, modelAnswer |

정규·PRN 처방과 측정 시각을 구별할 식별자를 둔다. 미확정 숫자를 임시 정답으로 채우지 않는다. DRAFT 데이터는 검토용으로 표시하고, 채점에 쓰이는 필수값이 미확정이면 해당 시나리오의 채점 검증을 보류한다.

확정 시에는 Figma·케이스·정답 키·모범 기록·시나리오를 같은 값으로 대조하고, [근거표](근거표.md)의 출처와 확인 상태를 연결한다.
