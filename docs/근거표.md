# 근거표

임상 내용과 교육 설계에 사용할 출처 후보를 모았다. 기존 검색 요약과 확인 상태를 보존한 목록이다. 2026-11-23에 PC-01 처방 약물(E-20·E-21·E-28·E-29)의 허가 용법 원문을 확인했다. 출처 등록이나 A/B 등급만으로 해당 주장이 검증되었다고 판단하지 않는다.

## 출처 등급

| 등급 | 기준 | 사용 |
|---|---|---|
| A | 학술지 논문, 공공기관·학회·의료기관의 공식 문서, 법령 | 원문·적용 대상 확인 후 사용 |
| B | 공식 성격의 교육 자료, 전문 의료정보 사이트, 의료기관 임상 경로 | 원문 확인 후 다른 근거와 대조 |
| C | 학생 과제·학습 자료, 블로그, 위키, 상업 템플릿 | 단독 근거 금지. 참고만 |

규칙: 임상 주장 1개 = 근거 ID 1개 이상. 환자 케이스·루브릭·모범 차팅에는 근거 ID를 달고, 등급 C만 있는 주장은 `[검증필요]`로 둔다.
