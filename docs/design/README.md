# 디자인

[Figma 원본](https://www.figma.com/design/MajtKIxofrlL0z8h294XvG?node-id=1-2)의 메인 페이지에서 `1차 MVP 요소` 프레임을 기준으로 작업한다. 같은 페이지 아래에 있는 기존 전체 화면은 참고용이다.

| 자료 | 용도 |
|---|---|
| [화면명세](../화면명세.md) | 구현할 화면과 동작 |
| [디자인 검토](디자인검토.md) | 2026-11-16 원본 확인 결과와 보완 사항 |
| [입력 화면 설계](신규화면-설계.md) | 입력·제출·결과 흐름 초안 |
| [wireframes/](wireframes/) | 로그인·개인 메인·입력 영역 등의 SVG 초안 |

SVG는 레이아웃 참고용이며 최종 시안이 아니다. Figma 원본, 화면명세, 확정된 케이스 데이터를 함께 확인한다. 아직 확정 시안 PNG는 저장되어 있지 않다.

구현할 화면이 확정되면 화면별 PNG와 Figma 노드 링크, 확인 날짜를 함께 기록한다. 내보내기 배율과 글자 크기는 실제 실행 화면에서 검토한다. 레퍼런스 페이지에 모아 둔 외부 서비스 이미지는 저장소의 자체 디자인 산출물에 포함하지 않는다.
