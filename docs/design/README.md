# 디자인 시안 폴더

Figma 디자인을 구현할 때 기준이 되는 PNG를 여기에 둔다. Claude는 Figma를 열 수 없다(로그인 필요). **여기 있는 PNG가 디자인의 전부**다.

## Figma에서 PNG 내보내는 방법

1. Figma에서 `간호차팅프로그램_front` 파일의 **'메인' 페이지**를 연다.
2. 화면 프레임 하나를 클릭해서 선택한다.
3. 오른쪽 아래 **Export**에서 PNG, **2x**를 고르고 **Export**를 누른다.
4. 파일 이름은 **프레임 이름 그대로** 한다. (예: `환자 정보 종합.png`)
5. 이 폴더(`docs/design/`)에 올린다.

## 순서

1. **'1차 MVP 요소'** 프레임 — 팀이 정한 1차 범위. 가장 먼저.
2. 화면명세의 우선순위 순서대로 나머지 화면
3. 컬러차트 페이지, EMR UI 컴포넌트 가이드 프레임

## 올리지 말 것

- **'레퍼런스' 페이지의 이미지**(다른 서비스의 화면 캡처). 저작권 문제가 있다.
- 실제 환자 정보가 보이는 캡처
- 개인정보, 키, 토큰이 보이는 화면
