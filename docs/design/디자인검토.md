# 디자인 검토

2026-11-16에 Figma의 메인 페이지 전체 배치, 1차 MVP 화면 4개, 로그인 프레임, 컴포넌트 가이드와 컬러차트를 확인했다. 아래 내용은 화면 구성에 대한 검토이며, 임상 내용의 타당성 검증은 포함하지 않는다.

## 전체 인상

남색 헤더, 연한 배경, 카드 단위 정보 구성은 병동 EMR의 분위기를 잘 전달한다. 환자 정보·투약·관찰·인계로 나눈 흐름도 이해하기 쉽다. 다만 실습자가 읽어야 할 정보와 직접 작성해야 할 영역의 구분이 약하고, 긴 문장과 양쪽 패널 때문에 본문이 좁다.

## 화면에서 확인한 내용

| 대상 | 확인 내용 | 보완 방향 |
|---|---|---|
| 공통 레이아웃 | 1280px 화면에서 왼쪽 메뉴가 256~288px, 오른쪽 채널이 320px를 차지한다. 본문은 672~704px다. | 실습 과제와 입력 영역에 본문 폭을 우선 배정한다. 채팅 패널의 처리 방식은 디자인 확정 때 결정한다. |
| 글자와 버튼 | 투약 화면의 일부 표·라벨과 SBAR의 인쇄·PDF 버튼에서 글자가 여러 줄로 끊긴다. | 실제 실행 크기에서 읽을 수 있는 폭을 확보하고, 긴 영문 병기는 보조 설명으로 옮기는 안을 검토한다. |
| 관찰 기록 | 화면 하단에 태그, 서술 입력란, `간호기록 등록` 버튼이 있다. | 기존 입력란을 바탕으로 시각·근무·처치·활력징후 입력 및 저장 상태를 보완한다. 입력 화면이 전혀 없다는 기존 설명을 수정했다. |
| 투약 기록 | 처방 표, 복용 상태, 구강 확인 체크, 전자서명 버튼이 있다. | 학생이 용량·경로·시각·결과·사유를 입력하고 저장하는 흐름을 명시한다. |
| SBAR | 작성된 인계 내용, 중재 체크리스트, 인수·서명 버튼이 있다. | 참고 자료와 학생 작성 영역을 구분한다. 모범 인계문은 제출 후 공개한다. |
| 로그인 | `main 로그인 화면` 프레임 안에 헤더와 배경이 있는 큰 영역이 있다. 아이디·비밀번호 입력 폼은 보이지 않는다. | 로그인·회원가입·개인 메인의 상세 화면이 필요하다. |
| 활력징후 차트 | MVP 관찰 화면에는 측정값 카드가 있고, 큰 추이 차트는 화면 밖에 분리되어 있다. | 최신 범위(D14)에 맞춰 활력징후 추이를 포함할 배치를 확정한다. VAS 시계열은 범위에 포함하지 않는다. |
| 구현 범위 | 실시간 채팅, 긴급 호출, 출력·서명, 격리·강박 카드 등 현재 MVP에 없는 요소가 보인다. | 구현하는 동작은 [화면명세](../화면명세.md)를 기준으로 한다. 시안에 있다는 이유만으로 기능을 추가하지 않는다. |

정적 화면을 확인한 결과다. 체크박스·버튼의 프로토타입 동작이나 키보드 접근성은 아직 검증하지 않았다.

## 환자 정보의 일관성

같은 실습에서 사용할 화면에 서로 다른 예시 데이터가 섞여 있다.

- 환자 정보·투약 화면: `김하늘 / 28세 / 여 / SIM-P01 / 501-1호`.
- 관찰·SBAR 상단: `이민석 / 남 / 34세 / 502호`.
- 관찰 본문: `김하늘 / 508호 / 경계성 인격장애(BPD)`.
- SBAR 본문: `김하늘 / 502호 / 조현정동장애`.
- 입원 유형은 동의입원·자의입원·보호입원 표기가 섞여 있다.
- 환자 정보의 현재 처방은 Olanzapine 15mg, 투약·SBAR에는 Aripiprazole 10mg이 보인다. 리튬의 복용 시간과 1회 용량도 화면마다 다르다.

정규 처방과 PRN 처방, 과거 처방과 현재 처방이 다른 것은 가능하다. 따라서 숫자를 일괄 치환하지 않고, 어느 시점의 어떤 처방인지 구분한 뒤 PC-01의 기준 데이터를 정한다. 상세 확인 항목은 [환자 케이스](../환자케이스.md#확인할-항목)에 모았다.

## 시각 스타일

| 자료 | 관찰한 특징 |
|---|---|
| MVP 화면 | 남색 헤더·파란색 강조, 연한 푸른 배경 |
| EMR UI 컴포넌트 가이드 | 청록색 간호실습 EMR와 노란색 Smart ENR 예시가 함께 있음 |
| 컬러차트 | 노랑 `#F4DA20`, 파랑 `#20A4F4`, 보라 `#6F20F4`를 기본색으로 안내 |

어느 자료를 최종 스타일 기준으로 사용할지 아직 정해지지 않았다. MVP 화면의 분위기를 유지하는 안을 우선 검토하되, 버튼·입력칸·상태 배지·글자 크기를 하나의 기준으로 정리한 뒤 Theme에 반영한다. 색상 대비 수치는 별도 측정이 필요하다.
