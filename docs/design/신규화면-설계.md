## 설계 기준

입력 영역은 기존 화면을 읽으면서 작성할 수 있는 위치에 둔다. 필수 항목과 저장·제출 상태를 명확히 표시하고, 오류가 있어도 작성 내용을 유지한다. 학생 작성 기록과 기존 기록은 시각과 출처로 구분한다.

결과 패널은 잘 작성한 내용·누락·불일치와 해당 입력 위치를 연결한다. 모범 기록은 제출 후 공개하며, AI 해설 상태와 규칙 점검 결과를 구분한다.

가입 시에는 다른 서비스에서 쓰는 비밀번호를 사용하지 않도록 안내한다. 가입 항목과 비밀번호 정책은 확정 후 반영한다.

활력징후 추이를 포함할 공간이 필요하다. 색상·글자·버튼의 최종 기준은 현재 MVP 시안, 컴포넌트 가이드, 컬러차트의 차이를 정리한 뒤 확정한다. 구체적인 보완점과 원본 위치는 [디자인 검토](디자인검토.md)에 있다.
