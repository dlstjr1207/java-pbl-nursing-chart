# 신규 화면 설계 (와이어프레임 초안)

| 항목 | 내용 |
|---|---|
| 상태 | **초안.** 디자인 담당이 Figma에서 다시 그리는 **참고용**이다 (Figma 파일은 Claude가 수정할 수 없어서 이 방식으로 만들었다) |
| 대상 | 디자인에 없는 화면: 로그인, 회원가입, 개인 메인(결과 패널 포함), 입력 영역 3개, 왼쪽 메뉴 정리 |
| 기준 | [기획안.md](../기획안.md) 4장, [화면명세.md](../화면명세.md), [시나리오.md](../시나리오.md) |

## Figma로 가져가는 방법

1. `docs/design/wireframes/*.svg` 파일을 **Figma 화면에 끌어다 놓는다**(Drag & Drop). SVG가 편집 가능한 도형·글자로 들어온다. 글꼴은 Figma가 대체한다.
2. 기존 디자인의 **색·글꼴·간격**(컬러차트, 컴포넌트 가이드)에 맞춰 다시 입힌다. 이 와이어프레임의 색은 디자인에서 읽은 주 색(`#00236F`, `#444651`, `#757682`, `#F8F9FF`)을 쓴 **임시 값**이다.
3. 다 그리면 화면별 PNG를 `docs/design/`에 올리고 [화면명세.md](../화면명세.md)를 고친다.
4. **와이어프레임의 문구와 버튼 이름은 임시**다. Figma에서 이름을 정하면 [시나리오.md](../시나리오.md)도 같이 고친다.

> 와이어프레임은 레이아웃과 필요한 요소를 정하는 용도다. 시각 디자인(색, 그림자, 아이콘)은 기존 4개 화면의 스타일을 따라 디자인 담당이 결정한다.

## 화면별 설계 메모

### 로그인 · 회원가입
- 로그인 실패 문구는 **아이디/비밀번호 중 무엇이 틀렸는지 알려 주지 않는다.**
- 회원가입: 이름, 아이디, 비밀번호, 비밀번호 확인, 소속·경력 단계. 중복 아이디는 거부하고 안내.
- 안내 문구: "다른 서비스에서 쓰는 비밀번호를 사용하지 마세요". 하단에 "교육용 예시 · 임상 검수 전".
- `TODO(팀)`: 비밀번호 정책(최소 길이 등) — tasks D-14

### 개인 메인
- **상단:** 사용자 이름, 로그아웃
- **실습 시작:** 무작위 출제(환자 케이스를 고르는 화면은 없다)
- **평가지표:** 총 실습 횟수, 최근 점수, **점검 항목별 평균**(R1, R6·R7, R8, R9), 최근 5회 추이. 막대 그림의 숫자는 예시
- **결과 패널:** 방금 제출한 실습의 `잘 쓴 내용` / `누락한 내용` / `잘못 쓴 내용`, 지적된 문장 하이라이트, AI 해설, 개선된 예시(**제출 후에만 표시**), [다시 실습하기]
- **과거 실습 기록:** 일시, 환자 케이스, 점수, [결과 보기]. 다른 사용자의 기록은 보이지 않는다

### 왼쪽 메뉴
- 남기는 것: **개인 메인 / 환자 정보 종합 / 활력징후 & 이상행동 관찰 / 정규 루틴 투약 점검 / SBAR 듀티 인계 리포트 / 로그아웃**
- 지우는 것: PRN 필요시 투약 관리, 간호 기록 및 바이탈·상담, 정신상태검사 MSE 사정, 리튬 TDM 검사·일정, Full-Battery / MMPI 결과, To-Do 예정 처치·지시사항
- 현재 화면은 활성(진한 배경)으로 표시한다
- 제목의 영문 병기(예: "(Patient Overview)")는 **한글만 쓸지** 정한다 — `TODO(디자인 담당)`

### 입력 ① 관찰 기록 추가 (활력징후 & 이상행동 관찰 화면에서 열림)
- 필수: 시각, 근무(Day/Evening/Night), 분류 태그(1개 이상), 서술
- **서술 칸 안내문**으로 학습 목표를 그대로 보여 준다: 환자 발언은 따옴표로 인용, 관찰은 장소·행동·정도를 사실로, 진단·해석 표현 피하기
- 선택: 처치, 활력징후(혈압·맥박·호흡·체온)
- 서술이 비어 있으면 저장 불가
- 저장하면 관찰 로그에 **시각 순서**로 들어간다
- `TODO(팀)`: **분류 태그 목록** 확정(예: 안정 회복, 불안 급증, PRN 투여, 식사·수면, 자해 관련, 기타)

### 입력 ② 투약 기록 추가 (정규 루틴 투약 점검 화면에서 열림)
- 약은 **처방 목록에서만 선택**(자유 입력 금지), 용량·경로·시각·결과(투여/거부/보류)
- **거부·보류·PRN이면 사유 필수**
- 처방 근거(정규 처방/주치의 구두 처방), 구강 은닉 검사(확인함/확인하지 못함 + 메모), 재평가 계획
- 학생이 입력한 용량·경로·시각은 처방 값과 비교해 R7로 점검한다

### 입력 ③ SBAR 작성 (SBAR 듀티 인계 리포트 화면)
- S·B·A·R 네 영역. **R은 (시각 + 할 일) 행을 추가**하는 형태
- 영역마다 안내문(무엇을 써야 하는지)
- **네 영역 중 하나라도 비면 제출 불가**, 상단에 "비어 있는 필수 영역: …" 표시
- [임시저장], [제출]. 제출하면 개인 메인으로 돌아가 결과 패널이 열린다
