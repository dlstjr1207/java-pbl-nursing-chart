## 00. 지금 필요한 자료 — 화면 기준 체크리스트 (먼저 읽기)

> 이 장은 "자료가 뭐가 필요한지 모르겠다"를 풀기 위해 **Figma 화면에 나오는 용어·값**을 기준으로 다시 정리한 것이다. 화면에 나오는 모든 임상 값은 **근거가 있어야 PC-01에 쓸 수 있다.** 링크는 검색으로 찾은 **후보**이고 원문은 직접 열어 확인해야 한다. 찾으면 [근거표.md](근거표.md)에 E-xx로 올린다.

### 요약: 가장 먼저 찾을 것 5가지 (P1)

1. **로라제팜 용량**(#1) — 디자인의 값 통일과 R7 점검 정답에 직접 필요
2. **아리피프라졸·리튬 허가사항 현행 확인**(#2, #3) — 허가보고서는 오래된 것일 수 있음
3. **벤즈트로핀 철자와 국내 허가**(#4) — 화면에 틀린 철자가 있을 수 있음
4. **판단·낙인 표현 목록의 근거**(#15, #16) — R1·R5의 정확도 좌우
5. **관찰 기록 분류 태그**(#17) — 입력 영역 ①을 그리려면 필요

### 못 찾은 것에 대한 원칙

못 찾은 항목은 **임의로 채우지 않는다.** 환자케이스에 `[검증필요]`로 남기고, 결과물의 "한계" 문장에 "근거를 찾지 못한 항목: …"을 적는다. 국내 기준이 없는 것(안전 라운딩 간격, 구강 은닉 검사 절차)은 "병원마다 다를 수 있음"으로 표기한다.

## 7. 수집·사용 규칙

1. **원문을 통째로 복사하지 않는다.** 요약하고 출처 링크를 단다. (저작권, DS-05)
2. 사용하는 모든 외부 자료는 **근거표(E-xx)에 올린다.** 올리기 전에는 환자 케이스·사전에 쓰지 않는다.
3. **등급 C(학생 자료·블로그·위키)만으로는 확정하지 않는다.** 교재·논문·공공기관 자료를 찾는다.
4. 데이터를 가공해서 파일로 만들 때는 **출처 ID를 파일에 남긴다**(JSON의 `source` 필드).
5. **라이선스가 불명확한 자료는 쓰지 않는다.** 확인할 때까지 상태를 "이용 조건 미확인"으로 둔다.
6. **실제 환자 정보는 어떤 데이터에도 넣지 않는다.**
7. 외부 API는 MVP에서 쓰지 않는다(DS-21, DS-22). 필요하면 **내려받아 필요한 부분만** 정리해 `drugs-mini.json`에 넣는다.
