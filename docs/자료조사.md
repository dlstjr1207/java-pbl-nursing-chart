| 항목 | 내용 |
|---|---|
| 상태 | 초안 (2026-11-16). 웹 검색 요약으로 출처 후보를 모았고, **링크를 열어 원문을 확인한 것이 아니다** |
| 쓰는 사람 | 팀 전원. 담당자가 자기 줄의 "상태"를 고친다 |

## 0. 한눈에 보기

우리가 쓰는 자료는 세 종류다.

| 종류 | 설명 | 예 |
|---|---|---|
| ① 외부 자료 | 법령, 용어·코드 체계, 약물 정보, 평가 도구. **참고하고 링크한다(원문을 통째로 복사하지 않는다)** | 의료법 시행규칙, KCD, 식약처 약물 정보 |
| ② 우리가 만드는 데이터 | 프로그램이 읽는 JSON·텍스트 파일. 근거 ID를 달아서 만든다 | 시나리오 JSON, 판단 표현 사전, 약물 미니 목록 |
| ③ 사용자가 만드는 데이터 | 프로그램을 쓰면서 생기는 데이터 | 계정, 사용자별 실습 결과 |

범위 표시: **MVP**(12/14까지 필요) / **2차**(이번에 안 씀) / **참고**(읽고 한계만 밝힘)

## 7. 수집·사용 규칙

1. **원문을 통째로 복사하지 않는다.** 요약하고 출처 링크를 단다. (저작권, DS-05)
2. 사용하는 모든 외부 자료는 **근거표(E-xx)에 올린다.** 올리기 전에는 시나리오·사전에 쓰지 않는다.
3. **등급 C(학생 자료·블로그·위키)만으로는 확정하지 않는다.** 교재·논문·공공기관 자료를 찾는다.
4. 데이터를 가공해서 파일로 만들 때는 **출처 ID를 파일에 남긴다**(JSON의 `source` 필드).
5. **라이선스가 불명확한 자료는 쓰지 않는다.** 확인할 때까지 상태를 "이용 조건 미확인"으로 둔다.
6. **실제 환자 정보는 어떤 데이터에도 넣지 않는다.**
7. 외부 API는 MVP에서 쓰지 않는다(DS-21, DS-22). 필요하면 **내려받아 필요한 부분만** 정리해 `drugs-mini.json`에 넣는다.
