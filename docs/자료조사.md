# 자료조사

출처 후보와 필요한 데이터 목록이다. 검색 요약으로 수집한 자료가 많으며, 이번 문서 정리에서 임상·법령 원문을 새로 검증하지 않았다. 실제 사용 전 원문·적용 대상·이용 조건을 확인한다.

환자 기준값은 [환자케이스](환자케이스.md), 출처별 검증 상태는 [근거표](근거표.md), 담당과 일정은 [작업 목록](tasks.md)에서 관리한다.

## 화면별 조사 항목

화면의 예시 수치는 PC-01의 확정값이 아니다. 우선순위는 P1(케이스 확정 전), P2(사용자 테스트 전), P3(후속 검토)로 구분한다.

## 예정 데이터 파일

파일은 구현 전의 구성안이다. 필드 정의는 기획안을 따른다.

|---|---|---|

| `scoring/stigma-terms.txt` | R5 표현 목록 | MVP |

사용자 데이터는 로컬 계정과 실습 결과다. 실습 결과에는 관찰 기록·투약 기록·SBAR, 점검 결과와 AI 해설을 저장한다. 계정의 비밀번호는 해시와 솔트로 저장한다.

## 조사 기록 방법

출처 ID, 적용할 항목, 원문 확인일, 확인자, 이용 조건을 함께 기록한다. 임상 값은 검색 요약만으로 확정하지 않는다. 근거표에 등록한 자료도 확인 상태가 미완료이면 사용을 보류한다. 자료의 출처 등급과 주장 검증 상태는 별개로 관리한다.

PC-01 처방·기록·SBAR에 필요한 자료를 우선 확인한다. 별도 MSE·위험사정·간호진단 목록 조사는 후속 범위다. 구체적인 조사 배정은 작업 목록 D-01·D-13에서 관리한다.
