# 작업 목록

기능 범위는 [기획안](기획안.md), 역할은 [팀 분담](팀분담.md)을 따른다. 작업 ID는 기존 기록과 연결하기 위해 유지했다. 완료 항목에는 날짜와 결과 링크를 남긴다.

- [ ] D-07 기획안의 미결 사항 확정

## 구현

기반 작업은 설계와 병행할 수 있다. 케이스 채점과 화면 연결은 해당 데이터·명세 확정 후 검증한다.

| ID | 작업 | 완료 기준 |
|---|---|---|
| T-00 | Maven Wrapper, 빌드, JUnit 실행, GitHub Actions, 실행 JAR | 빌드·테스트·실행 절차 재현 |
| T-01 | PatientCase·Patient·Medication·Attempt 모델 | JSON 왕복 시 필수 데이터 보존 |

| T-04 | R7 값 일치, R8 필수 입력 | 처방 종류·시각 구분, 미확정 값 처리, 필수값 누락 검증 |
