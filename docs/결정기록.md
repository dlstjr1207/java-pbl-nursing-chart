# 결정기록

현재 적용 범위를 먼저 요약하고, 변경 경위는 아래 이력으로 보관한다. 이전 결정이 후속 결정으로 바뀐 경우 최신 내용을 따른다.

## 현재 적용

| 항목 | 결정 | 근거 ID |
|---|---|---|
| 사용자 | 로컬 회원가입·로그인, 사용자별 기록. 서버 DB 없음 | D10 |
| 화면 | 기본 6화면과 회원가입 보조 화면 | D13 |
| 차트 | 활력징후 추이 포함, VAS 시계열 제외 | D14 |
| 학생 입력 | 관찰 기록·투약 기록·SBAR | D15 |
| 환자 | 첫 버전은 PC-01 한 명 | D16 |
| 후속 범위 | 별도 MSE·위험사정 입력과 R3 | D17 |
| 결과 | 개인 메인에 결과·평가지표 | D17 |
| 점검 | R1·R2·R4·R5·R6·R7·R8·R9. AI는 해설만 제공 | D4, D18 |

## 문서 정리 기록

2026-11-16에 README·팀 안내·작업 목록의 이전 범위를 최신 결정에 맞췄다. Figma 원본에서 확인한 관찰 입력란, 환자 정보 차이, 차트 배치와 스타일 차이를 화면명세·디자인 검토에 반영했다. 미확정 값을 임의로 정하지 않고 케이스의 확인 항목으로 모았다.

기준 시나리오는 확정 데이터 대입 후 검증하는 흐름으로 정리했다. 기존 후속 로그와 학생 입력을 구분하고, 모범 기록의 필수값 누락 상태를 만점으로 가정하지 않도록 했다. 이는 문서 일관성 수정이며 임상 값의 승인이나 기능 구현 완료를 뜻하지 않는다.

## 미결 사항

PC-01 기준값, 점검 가중치·표현 기준, 계정 정책, 차트 구현 방식, 최종 스타일, AI 예산과 수업 요구사항. 담당과 상태는 [작업 목록](tasks.md)에서 관리한다.
